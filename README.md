# Portfolio Website

A modern, responsive portfolio website built with React and Vite.

## Features

- 🎨 Modern, beautiful UI design
- 📱 Fully responsive across all devices
- ⚡ Fast performance with Vite
- 🎯 5 complete pages: Home, About, Projects, Skills, and Contact
- 🎭 Smooth animations and transitions
- 🔗 React Router for navigation

## Pages

1. **Home** - Landing page with hero section and features
2. **About** - Personal information, journey, and experience timeline
3. **Projects** - Portfolio showcase with project cards
4. **Skills** - Skills and technologies with progress bars
5. **Contact** - Contact form and information

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Technologies Used

- React 18
- React Router DOM
- Vite
- CSS3 (Custom properties, Grid, Flexbox)

## Customization

You can easily customize:
- Colors in `src/index.css` (CSS variables)
- Content in each page component
- Styling in individual CSS files
- Contact information in `src/pages/Contact.jsx`
